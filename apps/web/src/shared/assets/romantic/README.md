# Romantic home artwork

The raster illustrations in `assets/` are original artwork supplied by the
project owner for the private couples journal experience. They are bundled
locally with the web application; the romantic home loads no remote artwork at
runtime.

The production direction combines:

- French sticker-journal paper, tape, ticket, stamp, and envelope motifs.
- Spring botanical picture-book peonies, lily-of-the-valley, petals, and
  butterflies.
- Restrained motion: falling petals and one floating butterfly, disabled when
  the operating system requests reduced motion.
