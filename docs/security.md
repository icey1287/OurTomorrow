# 隐私与安全

## 两人身份

`boy` / `girl` 是本地角色选择，不是密码或 Session。应用必须部署在只有两个人能访问的私有入口后，不能直接公开到互联网。

## 位置

- 只在用户点击定位按钮时读取一次浏览器位置。
- 不持续监听，不保存轨迹，不在后台定位。
- 高德 Key 只存在于 API 环境变量中。
- 地图预览接口先校验状态属于当前情侣空间且仍有效。

## 留言

API 根据当前角色固定推导收件人，不接受客户端提交任意 `recipientId`。双方只能读取同一情侣空间内由自己发送或接收的留言。

## 浏览器数据

浏览器只保存 `our-tomorrow-role`。留言、位置和情侣设置都以服务器数据为准。

## HTTP

Caddy 默认限制 Frame、对象、表单目标、摄像头和麦克风；定位仅允许本站。生产环境必须使用 HTTPS，否则手机浏览器不会提供定位能力。
