# 视觉规范

## 方向

整体是“法式贴纸手账 + 春日植物绘本”，所有页面优先适配手机。

- 纸张：暖米白、轻横线、书脊、胶带和轻微纸纹。
- 植物：铃兰、雏菊、芍药与春日花卉角落。
- 动物：蝴蝶只作为低频引导和过场，不持续干扰阅读。
- 强调色：砖红、旧绿、墨棕，避免通用高饱和粉色模板。

## 页面重点

- 登录页只让手账认出当前使用者。
- 首页第一屏首先看到对方的此刻，其次是自己的更新入口，最后是留言。
- 设置页像一个小抽屉，不扩展成功能中心。
- 不使用底部菜单。

## 动效

- 身份确认使用完整翻页进入动画。
- 花瓣只在进入、发送成功等短暂时刻出现。
- 蝴蝶飞舞必须有明确路径并在数秒内结束。
- 弹层使用柔和上滑；不得加入无限循环的大面积粒子。

## 文案

简短、具体、像写在便笺上的话。避免积分、打卡、任务、连续天数焦虑和系统化术语。

## 触控

主要触控目标至少 44×44 px；底部弹层适配安全区；最小支持宽度 320 px。
