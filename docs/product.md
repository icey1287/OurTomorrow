# 产品边界

OurTomorrow 是两个人私用的手机端情侣手账，不是社交平台，也不是功能集合。

## 保留功能

### 写下名字

- 只识别固定的两位使用者。
- 成功后播放完整的翻页进入动画。

### 今天

- 查看对方的当前状态、位置和更新时间。
- 更新自己的状态、手填位置，或主动读取一次定位并选择附近建筑。
- 点击对方的位置，查看高德地图预览并可跳转高德地图。
- 写一张独立留言；首页只展示最新一张。
- 每张留言可选配一张照片，发送前在手机端自动压缩。
- 便笺匣按时间展示全部往来、未读数量和已读状态。

### 设置

- 修改共同纪念日。
- 修改首页扉页句子。
- 查看在一起天数。
- 切换当前使用者。

## 明确不做

- 回忆、日记、心情、愿望、计划、胶囊、每日惊喜或年度回顾。
- 独立相册、批量图片、导出、回收站、站内通知或后台任务。
- 持续定位、位置轨迹或后台定位。
- 底部多栏菜单、积分、打卡或关系评分。

少就是产品本身，不是临时删减。
